## Introduction

`@processpuzzle/base-ai` is the front-end building block of ProcessPuzzle's AI capabilities. Its first feature is
**object recognition**: enrolling identifiable objects (e.g. sailboats by sail number) from photos, and
identifying them in uploaded videos, with a manual review step for low-confidence matches. It complements the
[`base-ai-backend`](../../java-shared/base-ai-backend/README.md) Spring Boot module.

See [the recognition design](../../../docs/ai/boat-recognition-design.md).
