## Introduction

`@processpuzzle/base-artifact` is the front-end building block of the ProcessPuzzle Artifact management. It provides the Angular constructs needed to describe, upload and render the artifacts (documents, media, generated output) a Low-Code application produces and consumes. The library complements the [`base-artifact-backend`](../../java-shared/base-artifact-backend/README.md) Spring Boot module that stores artifacts and their metadata server-side.

## Status

This library is currently a scaffold. The public API will grow as artifact management takes shape.
