**Containment, child in a table of its own.** A `Test Entity Component` belongs to exactly one `Test Entity`, but it is persisted through its own endpoint and points back at its parent through the `testEntityId` foreign key — the way an RDBMS models a child table. The parent's `components` attribute therefore holds ids, and deleting a row there deletes the component itself. ```typescript // Test Entity Component const nameAttr = new BaseEntityAttrDescriptor('name', FormControlType.TEXT_BOX, 'Name', undefined, true); const descriptionAttr = new BaseEntityAttrDescriptor('description', FormControlType.TEXTAREA, 'Description'); const testEntityAttr = new BaseEntityAttrDescriptor('testEntityId', FormControlType.FOREIGN_KEY, 'Test Entity'); testEntityAttr.linkedEntityType = 'Test Entity'; new BaseEntityDescriptor({ entityName: 'Test Entity Component', attrDescriptors, componentParent: 'Test Entity', isEmbedded: false }); // on Test Entity const componentsAttr = new BaseEntityAttrDescriptor('components', FormControlType.COMPONENTS, 'Components'); componentsAttr.linkedEntityType = 'Test Entity Component'; ```
