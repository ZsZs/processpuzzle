# ProcessPuzzle Demo Video — Character Clip Prompts
### One clip per scene, ready to paste into HeyGen (or D-ID) Photo-to-Video

Base image: one static, front-facing portrait of the character, drawn once in the existing watercolor/hand-drawn icon style. Use the SAME image for all 8 clips for visual consistency.

For each clip below: **Script text** = paste as the spoken line (drives lip-sync + auto expression). **Direction note** = optional extra prompt text for gesture/emotion, if the tool supports a separate "acting instructions" field; otherwise just let auto-expression handle it from the line's tone.

**Script text:**

**Direction note:** Warm, welcoming opening tone; friendly nod/wave toward camera at the very start.
